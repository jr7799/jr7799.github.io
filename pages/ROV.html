NOAA ROV IK Arms

This demonstration is from a intership evolved contracting job with NOAA, the National Oceanic and Atmospheric Administration. The goal of this project was to create a system that would allow for inverse-kinematics control of the ROV's arms, allowing for more precise and intuitive manipulation of objects in the underwater environment. This project was built using Unreal Engine and their built in control rig system. It showcases the capabilities of the ROV's arms movement within a empty level of Unreal Engine.
